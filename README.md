A fast, dependency-free CSV reader that returns exactly csv-reader 1.0.0's answers on broken CSV files — the same {columns, rows, errors}, at a fraction of its CPU time. It reads each case once, left to right, slicing fields from the input instead of building them character by character, and skips quoted fields with indexOf.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
